# rubrics — 个人评价体系引擎（seed）

这是一个**独立子项目**，与仓库里其它功能解耦：不 import `scripts/research.py` 等外部模块，
只用自己的存储和核心逻辑。

**模块边界（当前定位）**：作为独立模块**在本仓库内试点**——代码、文档、schema 跟主仓库一起
版本管理和同步；运行数据（`data/`、`proposals/`）单独 gitignore。将来如果成熟，可以整体拆成
独立仓库，届时只需搬走这个目录，不依赖主仓库任何东西。

## 它在解决什么

把我的**评价体系**（我对事情的要求、扣分点、判断标准）当成一等公民的记忆来积累——
不是记我的习惯和技能，而是记**我在什么情境下、出于什么、给出了什么评价**。

## 核心原则（seed 阶段即固定）

1. **情境绑定，不用置信度**：每条标准只在特定情境下成立；没有"低置信度"，
   只有"在哪些情境下成立、在哪些情境下被推翻"。
2. **只增不减 + 沿革**：不覆盖旧条目；新证据用更窄的情境切分，冲突记录在沿革里。
3. **读时组装**：条目不提前固化清单，面对新事务先做情境快照，再匹配；匹配不上就问，不猜。
4. **RSI 式演进**：本项目用自己的产出改进自己——见 DESIGN.md 的演进循环。
