# 小红书跟踪设置

跟踪对象：**tabris 🗝**（小红书号 2608032230），主页 <https://www.xiaohongshu.com/user/profile/60a72ded000000000101de6e>。
他常发英文论文截图，所以流程按「一张截图一条」：读主页 → 找新笔记 → 下载截图 → 本地 OCR（macOS Vision）→ 认出截图里的论文（先找 arXiv 编号，找不到就按 OCR 出的标题检索 arXiv）→ 拉 arXiv 摘要 → 按 HF 日报同款写法生成一句中文 + 标签 + 论文/PDF 链接，并附小红书本帖入口 → 写进 [[今日简报]] 的「小红书」段落，编号 X1、X2。

认出论文的条目以 arXiv 编号作为归档 ID（和 HF 日报里的同一篇合并归档）；认不出的截图按原帖处理，ID 形如 `xhs-<笔记ID>-<第几张>`。

小红书网页端必须登录才能读主页，登录态保存在 `~/.local/share/research-xhs/cookies.json`（0700 目录，不进 Obsidian 仓库）。本地服务 `local.research.xhs`（端口 18060）复用同一份登录态。

## 登录失效时

症状：早报里出现「小红书部分本次未更新（RuntimeError: 主页页面没有内嵌数据）」，或页面提示「电脑设备登录超限，请重新登录」。处理：

```sh
python3 /Users/zhangshuo/Research/scripts/xhs.py run --date $(date +%F)   # 先看报错
launchctl bootout gui/501/local.research.xhs                              # 避免浏览器实例冲突
cd ~/.local/share/research-xhs && XHS_BROWSER_BIN="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" ./xiaohongshu-login-go
launchctl bootstrap gui/501 ~/Library/LaunchAgents/local.research.xhs.plist
```

扫码窗口出现后用手机小红书 App 扫码。注意：同一个账号的网页端登录数有限，扫码后不要在其他浏览器再登录同一账号，否则会把这里挤掉。

## 抓取参数

用户 ID 与 `xsec_token` 保存在 `.research/xhs/target.json`；已处理过的笔记 ID 在 `.research/xhs/seen.json`，用于去重。
笔记正文、OCR 文本、截图、中文简介在 `.research/xhs/digests/<日期>.json`，截图文件在 `.research/xhs/images/<笔记 ID>/`。

手动补跑最近几篇（`--force` 会重新处理已见过的笔记）：

```sh
python3 /Users/zhangshuo/Research/scripts/xhs.py run --date 2026-09-25 --limit 3
```
