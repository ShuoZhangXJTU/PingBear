# 研究偏好

用户：NLP 算法博士，大厂 AI Lab 研究工作。避免基础术语科普；中文保留必要英文术语。

## 关注主题

1. Agentic 自我改进 / RSI：经验到技能、失败反馈、self-play、自动课程、环境生成、持续学习、自动研究、跨任务迁移。区分模型参数更新、记忆积累、prompt/代码/harness 改进，不能把单次 self-reflection 直接称为 RSI。关注多轮迭代增益及独立验证。
2. Harness：暂按 agent 的运行、训练与评测外层系统理解，包括工具、上下文/记忆、执行循环、环境、轨迹、验证器、预算与可复现性。区分模型能力与 harness 带来的提升。
3. 后训练：RLVR、GRPO/PPO、credit assignment、reward/verifier、on-policy distillation、agentic RL、数据合成与筛选、长程训练稳定性、训练与推理成本。

## 日报与归档

一句话说清做了什么、有什么好处或用途，通常 35–75 字。语气像给同事随口介绍，别堆概念、别用翻译腔。不展示机构，不需要额外核实机构，不写阅读依据、推荐理由、待核对段落。保留原始来源供内部追溯，不编造论文没有支持的效果。
参考语气：“提了metaRSI，对模型、harness、数据分别拆开做自优化和组合，优势在于防reward hacking，有工业界落地意义”。仅模仿表达方式，不把这句话的事实套用给别的论文。
归档可直接一键保存；点“加备注”允许补一两句，保存到独立论文笔记，避免每日刷新覆盖。已归档条目可继续补充备注。
用户选择后才归档。记录选择理由及后续评价，作为将来筛选调整的依据；不要把沉默当作不喜欢。
