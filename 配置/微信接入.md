# 个人微信接入

通过腾讯 ClawBot / iLink 协议连接个人微信，桥接本机 Codex 与 Research 仓库。协议依据：[腾讯官方文档](https://github.com/Tencent/openclaw-weixin/blob/main/docs/protocol.md)。这是独立微信会话，不是把原始 Codex 对话线程搬到微信；共享研究偏好、最近 3 份日报和最近 10 篇归档笔记。

## 绑定

```sh
python3 /Users/zhangshuo/Research/scripts/weixin_bridge.py login
```

手机微信扫描本机生成的二维码并确认。二维码位置：`~/.local/share/research-weixin/微信扫码绑定.png`。二维码过期可重新运行。若微信提示验证码，输入 `~/.local/share/research-weixin/verify-code.txt`，等待绑定程序继续。

本地服务 `local.research.weixin` 已准备为登录成功后启动。扫码凭据保存在用户私有目录（0700，文件 0600），不写入 Obsidian 仓库。只有扫码绑定的用户 ID 可交互；其他用户及群消息被忽略。

## 使用

- `今日简报`：发送本地全量简报，长内容分条返回。
- `展开今天第 2 篇`：利用当前资料与对话上下文解释。
- `归档今天第 2、4 篇` 或 `归档 2026-09-25 2 4`：立即归档，重复操作不会覆盖已有笔记。
- `清空会话`：清空模型使用的微信对话上下文；消息去重记录和日志不删除。
- `帮助`：查看命令。

支持文字及平台提供的语音转写；图片、文件、语音识别、群聊尚未实现。普通问答为只读，不执行远程任意电脑操作，也不自动抓取发送的网页链接。归档由固定命令处理。模型不会因自然语言讨论“是否值得归档”就修改资料。

## 运行与状态

电脑需开机联网，复用现有 Codex 登录和额度。微信会话及运行日志保存在 `~/.local/share/research-weixin/`，不向第三方二维码服务发送绑定链接。

```sh
python3 /Users/zhangshuo/Research/scripts/weixin_bridge.py status
launchctl print gui/501/local.research.weixin
```

`waiting_for_scan` 表示尚未绑定；`connected` 表示服务已载入绑定账号；`last_reply_at` 表示已成功发送回复。只有后者加手机收到消息，才算收发端到端验证。账号失效需重新扫码。

暂停连接：`launchctl bootout gui/501 ~/Library/LaunchAgents/local.research.weixin.plist`。后台只对收到的消息回复，尚未启用每日主动微信推送。
